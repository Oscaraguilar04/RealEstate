# Esme Rodriguez — Acre & Signal Concept

A one-page concept website by [Acre & Signal](https://acresignal.com), showing how a residential real estate professional can be positioned online. Agent identity, listings, statistics, and testimonials are illustrative.

Open `index.html` in a browser, or launch it with the VS Code Live Server extension.
